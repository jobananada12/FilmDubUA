# FilmDubUA 🎬🇺🇦

Безкоштовна локальна програма для створення української озвучки відео.

## Перша версія
- вибір MP4/MKV/MOV відео;
- введення тексту озвучки;
- голос Windows через pyttsx3/SAPI;
- регулювання швидкості та гучності;
- експорт готового MP4;
- робота локально на ПК.

## Запуск Windows
1. Встанови Python 3.11+.
2. Встанови FFmpeg і додай `ffmpeg.exe` у PATH.
3. Запусти `start.bat`.

Або вручну:
```powershell
pip install -r requirements.txt
python app.py
```

Програма призначена для відео, на використання яких у тебе є відповідні права.
